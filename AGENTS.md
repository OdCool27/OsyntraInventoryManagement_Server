# Architecture documentation

For schema, API, dependency, workflow/state, security/tenant, integration, deployment or offline changes, review and update the shared [architecture documentation](../docs/architecture/README.md). Regenerate its source inventories and run the documented checks. Review curated diagrams/DSL against source; keep proposals separate and mark uncertain relationships. Do not install tooling without approval. The shared docs are outside this Git repository and must be preserved/versioned with the workspace.
